# 纪念包与订单状态遗漏补齐 · v1.17.3

总计划要求加载/失败/恢复真实、等待有界、不能重复提交或让旧异步结果覆盖当前选择。本轮复查补齐两个旅程，保留四主题、九语和现有模拟/统计/年月/存储/沙盒授权规则。

## 实际问题与修复

1. 工作台：样例加载失败时aria-busy仍为true；美术绘制失败时PNG/PDF按钮仍启用。现在加载失败清除忙碌；只有当前预览成功才允许导出或结账。编辑标题/寄语立即使旧预览失效，不能在150ms防抖窗口导出或购买旧画面。
2. 结账和订单：原购买函数在等待health后才重新读取当前作品/设计。现在点击时固定localId与设计，等待期间锁定模板、记录和编辑控件；失败恢复操作且保留明确错误。订单核验增加15秒超时，取消选择时清除忙碌并忽略旧响应，失败状态与文字一致；付费文件生成期间锁定订单与设计，失败后恢复。

没有改支付服务端、D1、Secret、价格、Webhook、幂等或导出授权。没有新增真实收款或Stripe测试交易；前端回调/结账并发测试均明确模拟。
