# 四主题计划遗漏补齐 · v1.17.1

## 本轮实现

- 恢复原六个游戏视图的真实控制器入口：首页设置、当前人生、人生回顾、批量模拟、家族树、本机人生。离开进行中的人生时暂停；进行中的人生未结束时禁止批量运行，保护当前随机序列。
- 辅助视图按现有四主题和九种语言呈现，包括本机空状态、批量结果和比较表、存档管理、记录详情和纪念墙。保存记录封面支持 Enter/Space，弹窗支持焦点、Tab 和 Escape。单条删除先显示真实记录姓名并确认。
- 日期只读：按既有摘要的 ts/country/name/age 身份匹配既有丰富记录年月；没有记录时明确说明缺失。没有更改 CalendarCore、模拟规则、人口输入、存储格式、个人寄语或原有回放结果。
- 失败场景图片可重试，手机继续使用手机资源；按钮在可点击层，已失败图片也可识别。底部入口在弹窗打开时隐藏，取消后恢复。
- 可选工具加载提示准确，加载成功后清除；站尾版本由发布元数据生成。既有 GA4、Clarity、Stripe/D1 配置保留，支付仍限测试。
