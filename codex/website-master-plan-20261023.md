整理日期：2026-10-23。以实际版本、验收和用户确认区分状态；参考图中的宣传数字不作为本站事实。此表整合历次需求，旧计划的初始“未发布／待完成”说明不能代替当前验收。

## 产品方向与约束

做一个可免费开始、愿意读下去、记得自己选择、愿意保存这段人生的浏览器人生模拟器。视觉保留蓝色品牌和四主题（清新蓝色、旅行手账、现代海报、电影夜景）；九语言共用组件。既有详细资料默认可访问。保留旧存档、旧回放、已购记录、既有统计和真实支付；不凭国家标签机械指定唯一族裔，不复制对手素材、文案和未经核实的在线人数。真实支付测试不扣款。

## 执行顺序

### 第一阶段：完成布局收尾

统一数字列标题、数值和缺失值对齐；文字列与行标识保持起始边对齐。检查表格、资料卡、控件、按钮、长标题与窄屏滚动。修复纪念包模板卡片在手机／平板上的文字裁切，保留清楚可点击的名称与预览。通过 102 项基础检查，以及 226 页 × 4 主题 × 5 宽度和 4 个动态状态的布局验收，再走 Git 自动发布并复核正式域名。

### 第二阶段：改造叙事与触发架构

把“固定年龄弹出通用问题”改成：前情铺垫 → 情境变化 → 合法选择 → 即时反馈 → 后续回响 → 回顾保存。

事件须记录人物、前置事件、当前学业／就业／家庭状态、触发窗口、冷却、选项、明确代价、已发生的结果和后续条件。年龄只限制范围；必须满足实际前情才能出现。普通日常留在年表，轻微选择可在卡内展开，真正需要决定的分岔才暂停。避免连续弹窗；任一时刻只激活一张决策卡。

建立稳定的朋友／重要人物身份和事件关系，不能每次随机换人。相识、联系、承诺、参与活动等由实际事件记录支撑。未发生的父母离世、迁移、职业或兴趣不得写进前情。按年运行时不虚构“已经三个月没联系”等精确月度间隔。

选项表达具体行动和合理取舍，先说明确定的时间／费用等代价；不确定的结果保留不确定性。自动模式也要有可解释、可重现的选择。收起、刷新、续玩不自动替玩家决定；阅读与收藏不消耗随机数或重复结算。

新叙事改变结果时采用新版本隔离，旧 v1/v2/v3 种子、存档和已购快照继续兼容。死亡模型保持；新增叙事随机性不能悄悄改变既有模型随机序列。

### 第三阶段：先完成三条端到端故事链

1. **重新拾起热爱**：已经记录的兴趣 → 后来搁置 → 再次出现的参与机会 → 报名／先了解／保留原安排 → 后来的实际经历。
2. **主动联系旧友**：已有朋友与共同经历 → 生活变化 → 再联系的机会 → 不同回应 → 对方的实际回应与关系后续。
3. **为家人留出时间**：在世家人及已有相处记录 → 时间安排冲突 → 陪伴／协调／保持安排 → 后续生活中的回应。

每条都覆盖前情、合法触发、不同分支、即时反馈、后续和结局回顾。某个选择不参与也要有尊重而完整的表达；不使用“没回家就让亲人去世”等惩罚制造内疚，不推断用户现实中的创伤或遗憾。

先检查用户能否说清“发生什么、为何现在要选、选择保留或放下什么、后来怎样”。三条原型通过后仍须继续全量迁移，不能以原型替代全部要求。

### 第四阶段：扩展到全部适用事件与抉择

统一重写现有日常叙述与抉择，逐类覆盖幼年、学习、朋友、恋爱、家庭、职业、迁移、健康与晚年。围绕没说出口的话、放下的热爱、稳定与未知、陪伴、失联和个人边界展开，日常温暖与重要转折保持节奏，避免整个人生只剩遗憾或灾难。

年表提供简短、具体的情境；入口随内容使用“读完这封信”“看看这次机会”“回应邀请”等动作。弹卡先呈现人物与情境，再给问题与行动。场景图对应正文与角色阶段；每条事实和数值影响可追溯。维护事件→前情→图片→互动→本地化清单，所有适用事件覆盖，无遗留的通用加分问答或重复占位回响。

### 第五阶段：让纪念包保存本人真实故事

把玩家实际选择、共同经历、后续和珍藏记录组织成个人篇章、转折及回望。封面、年表、数据和故事使用同一快照。免费预览明确展示本人内容；支付入口解释一次购买的实际交付，未支付保留锁定，付款权益由服务端确认。不得在旧已购内容里补写玩家没有经历过的新故事。

### 第六阶段：上线验收与观察

规则：非法人物／年龄／关系条件、冷却、重复结算、确定性回放、死亡截尾、旧存档和旧订单。

体验：四主题九语言，320／390／768／1024／1440 等宽度；键盘、触摸、阅读位置、弹卡节奏、图片失败、慢网、刷新与返回恢复。

内容：前情可追溯、选项有区别、结果与回响真实对应；不以文案条数替代内容质量。

商业与 SEO：本人预览→真实结账→未付款返回锁定；沙盒／模拟授权与真实扣款分别记录。保留 canonical、语言链接、226 条 sitemap 和真正 404，资料来源未知项保持明确。

发布：相关修改单独提交，通过 Git main 自动部署；核对 CI、活动部署、正式域名精确提交和功能；保留回滚版本。每阶段验收通过再进入下一阶段，不为验收报告重复部署。

观察：同类用户与流量窗口下比较首次推进、抉择完成、阅读回访、本人预览到结账及服务端确认购买。GSC 抓取／索引和转化变化属于上线后观察，不提前承诺效果；不自动创建定时任务。
