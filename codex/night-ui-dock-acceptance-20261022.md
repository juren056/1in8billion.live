# 电影主题与移动端浮栏验收（v1.22.1）

2026-10-22。执行计划：`codex/night-ui-dock-plan-20261022.md`。本文件记录本地验收，正式环境版本和结账复核另存发布回执。

## 完成内容

- 表格、隔行、悬停行、故事、证件、结局、按钮和提示的文字／背景成对跟随四种主题。共享表格样式失败时，基础隔行和悬停样式仍可读；手机统计列允许长数值和单位换行。
- 浮栏仅在首页主操作离开视口且向上滚动时显示；向下阅读、游戏、对话框、菜单、输入和页脚时隐藏。增加九语言收起按钮，并用 sessionStorage 记住本次访问的收起选择。保留继续、结束记录、重新出生及取消时保护存档的原有语义。
- 浮栏依据激活视图判断，修复页头滚出屏幕后的负坐标判断；样式先加载成功才启用辅助栏。外观／语言／导航菜单互斥，窄屏菜单限高且可滚动，Escape 恢复焦点。
- 修复消费选择弹窗引用未定义变量，自动执行状态读取现有 `life.autoInvest`。修复弹窗误用两列容器造成的狭窄布局，手机投资选项改为单列，补充中文说明和提示、九语言积蓄引导与出生人数单位。仅对该弹窗的系统文案显式本地化，继续保留其他动态／私人内容的翻译隔离。
- 生存图和家族树文字使用主题颜色。原有模拟公式、随机抽取、国家数值、年月、存档格式、真实支付配置未修改。
- 将辅助浮栏和导航增强的非必要资源推迟加载，保持既有首屏预算；没有提高预算上限。
