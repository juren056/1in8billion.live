# 六国情绪叙事执行与验收

基线：v1.24.0 / 7c638e65cbbb7e621b6473fbc455b003d180588d。
目标：v1.25.0，新增人生采用 v5；v1–v4 存档、回放及已保存的付费快照继续按原版本解释。

## 用户体验目标

让玩家感到自己的普通生活值得被理解，关系有记忆，选择有空间。不是用悲剧、倒计时或必胜奖励强迫选择。过去未联系的人不一定在等待；没有发生的相聚不能写成事实。角色去世后不再参加后续活动，玩家死亡后停止新剧情。

## 已实施的内容与交互

- 三条深故事：回到中断的兴趣、联系求学时认识的人、为仍在身边的家人留时间。每条三个选项，真实前情、即时结果、两年与五年后各一次不同的回响。
- 中国、日本、印度、美国、巴西、尼日利亚：每国十个独立日常场景，以及上述三条故事的本地背景改写。共 60 个本地日常、18 个本地故事适配；后续分支共享三个原型的语义，不冒充 18 套完全独立的民族志。
- 其他国家保留 160 个共享日常和 12 条共享故事，其中三个深原型同样有两次回响。不能宣传所有 172 国都有专属文化剧情。
- 国别只决定可用背景。人物参与资格仍依据实际年龄、已发生的求学/工作/兴趣中断、在世家人和此前联系，不根据国籍推断宗教、性格、个人遗憾或家庭语言。
- 日常留在时间线；可原地收藏并查看已收藏的真实瞬间。重要选择有前情和场景插画，暂停且可暂放。五年后回响有独立标题。
- 纪念包保留真实前情、选择及两次回响，长故事在 PDF 中按实际段落排版。正在进行的人生不会被伪装为可购买的完整人生；结束后沿用自己的卡片预览与真实支付入口。
- 九种语言均使用构建前生成并提交的静态文案；构建和游玩不调用翻译服务。翻译作者公开虚构文本时不发送玩家数据。

## 文化资料边界

背景资料、来源和适用限制见 `content/story-v5/provenance.json`。只参考公共文化、学习和阅读活动的可能形式，不承诺各地都有活动、不使用过期人数、不预测未来政策。画面沿用原创场景图集，不能作为真实国家或人物照片。扩展到更多国家前仍应结合实际玩法数据与母语文化编辑审阅。

## 验收门槛

1. 220 个日常、30 个故事定义、六国分流、全部分支、真实前提、两次回响、死亡中断、重复回调、刷新恢复及确定性测试。
2. 保留 v4 完整人生摘要为独立基准；再跑旧 v1–v3 全部 108 条证明。死亡源码合同 38,184 输入不变。
3. 浏览器实际运行新人生，覆盖 172 国；九语言、四主题、桌面/移动多宽度，长选择、图像失败、触屏、键盘与切换语言恢复。
4. 六模板三比例预览；A4/Letter 真正生成 PDF，逐页检查边界并抽页渲染。
5. 完整构建、数据、SEO、资源预算、单元测试通过。付款仍为真实单次 USD 2.99；仅验收结账页面和未付款返回锁定，不提交真实付款。
6. 通过 Git 推送 main，记录 GitHub CI 与 Cloudflare 精确提交。线上再次确认版本、文案包、配置、搜索页、游戏及真实支付入口。

## 发布及数据观察

发布前不把“已实现”写成“线上验收通过”。版本回退锚点为上述 v1.24.0 提交。只记录类别/动作/规则版本等粗粒度分析事件，不发送姓名、私人笔记、故事正文。上线后观察阅读、收藏、后续章节、恢复与自有人生预览的漏斗，不承诺转化率上涨。

执行中的结果与发布凭据将写入同目录验收记录。
