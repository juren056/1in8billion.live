GSC Performance is still processing and has no usable query table. Production CWV and organic conversion rates have not been established. Baseline and event meanings: MEASUREMENT.md. A local decoded-byte comparison reduces English translation loading from the 192,772-byte all-language file to roughly 17 KB. Actual production compression and latency differ.

The inherited demographic observations still have unknown years/provenance. Reference links do not validate them. No official national fact pages or broad keyword permutations are published. The model experiment verifies sampler behavior only.

Original advanced family/finance/lab tools remain available; some inherited narrative and advanced dialog text is not fully localized. Future manual-choice transcripts and calibrated country data require separate work, as in the original plan's longer-term items.
