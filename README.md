# 選出生地 / born-somewhere v2

> 在哪裡出生，曾經不是我們能選的——這個版本把它交還給你。

通用 172 國人生模擬遊戲。基於 1in8b.life 原作精神的二次重寫。

**v2 與 v1 的差別**：把原作的 172 國真實生命表、死因分布、出生證書、過去生命書架、3 語言 i18n 都做出來了。原作 1400 個函式的全部社會系統（種姓 / 寄養 / 收養 / 商業等）目前只建了 v0.1 骨架，後續補。

## 線上版

## 本地跑

```bash
python3 -m http.server 8766
# 然後開 http://localhost:8766
```

## 功能

- **172 國真實生命表**：每國有完整生命表，按 Gompertz 函數匹配期望壽命
- **死因分布**：7 桶（嬰兒/兒童/青年/中年/中老年/老年）+ 國家/個人加成
- **3 種出生模式**：此刻出生的嬰兒、80 億人活口、3 種年代
- **3 種語言**：繁體中文、简体中文、English
- **出生證書頁面**：guilloche 浮水印 + 證書樣式
- **生命進行畫面**：年齡進度條、性別/教育/工作/伴侶/子女
- **訃聞畫面**：含享年、當地平均壽命對比、過去生命數
- **過去生命書架**：每條命像一本書放在像素書架上
- **印度種姓**（v0.1 骨架）：SC/ST/OBC/General 機率分配、學校歧視事件、表單勾選
- **本地端儲存**：localStorage 存過去生命
- **無註冊、無上傳**

## 技術

- Vanilla HTML / CSS / JS，零依賴
- 生命表：Gompertz 函數，alpha/beta 參數依國家分性別平均壽命校正
- 死因：年齡分桶 + 國家/個人加成 + 個人抽菸/疾病調整
- i18n：簡單字典查表
- 部署：純靜態檔，可放任何 CDN
