

## 與 zu-pu 互通的歷史遺產

zu-pu v1（已歸檔於 rollroyces/zu-pu）的張氏 30 人範例家族可透過以下方式匯入 born-somewhere：

1. 從 zu-pu/data/demo.json 用 zu-pu/gedcom.js 的 `Gedcom.export(DB)` 轉成 GEDCOM 5.5.1
2. 將產生的 .ged 檔透過 born-somehere 族譜 tab 的「匯入 GEDCOM」按鈕載入
3. 透過中心人物下拉選單選「張文山」可看到完整三代家族（張守正、陳秀英為父母，已歿以 † 標示）

完整演示 born-somehere 對 zu-pu 範例的相容性。
