# 選出生地 / born-somewhere

> 在哪裡出生，從來不是我們能選的——這個版本把它交還給你。

一個人生模擬遊戲：選一個出生地，從 0 歲活到當地平均壽命，依真實公開統計隨機走完一生。

## 與原作的差異

這是根據 [1in8b.life](https://1in8b.life)（中文版「80億分之1」，由 1in8b.life 與 Claude 合作）原作的二次創作，差別只有一個：**出生地由使用者主動選擇**，而不是依人口比例隨機抽出。原作的隨機出生、世界年代、人生長度、沉重事件、暫停問題、追思館等核心機制都保留下來。

## 本地跑

沒有 build step、無依賴、無框架。打開 `index.html` 不行（會被瀏覽器擋 `fetch`），請用任何靜態伺服器：

```bash
python3 -m http.server 8765
# 然後開 http://localhost:8765
```

或 `npx serve`、Nginx、Cloudflare Pages、Vercel 等都行。

## 怎麼玩

1. 在 58 個國家卡片中選一個，或用搜尋 / 6 個地區分頁過濾
2. 設好世界年代（過去 / 現在 / 未來）、人生長度（30 分 / 1 小時 / 1.5 小時）、性別
3. 按下「出生」按鈕
4. 5 / 15 / 30 / 50 / 70 歲會停下來問你問題，寫下的話會收進追思館
5. 走到生命終點時會看到完整生命紀錄，可以複製、換個出生地再活一次

每一年的事件依國家真實統計抽樣：嬰兒死亡率、就學率、結婚年齡、生育數、職業分佈、收入（按吉尼係數）、重大疾病發生率、自殺率、他殺率⋯⋯ 死亡時間依當地分性別的生命表，死因依 WHO / GBD 模式分布。

## 哪些是真實資料

出生人數、男女平均壽命、嬰兒與 5 歲以下兒童死亡率、人均 GDP（PPP）、吉尼係數、平均受教育年數、大學就學率、農業就業比例、生育率、孕產婦死亡率、HIV 盛行率、兇殺率、自殺率、吸菸率、醫療自付比例、童婚率、生活滿意度。

資料來源：World Bank、UN WPP 2024、WHO GBD、UNDP。數字為公開統計概值，僅作模擬用途，不構成預測或建議。

## 沉重事件的處理

死亡、暴力、自殺等沉重事件照真實統計發生，**不描寫畫面**，並附上求助專線（衛福部安心專線 1925、生命線 1995、張老師 1980、撒瑪利亞 2389）。本版目前沒有原作的「教學版」模式，沉重事件全量呈現——如果你正在低潮，請聯絡身邊的人或當地的求助專線。

## 技術

- Vanilla HTML / CSS / JS，零依賴
- 響應式：桌機、手機、平板
- 資料：`data/countries.json`（58 國）
- 死亡模型：Gompertz 函數，α / β 參數依國家分性別平均壽命校正；嬰兒 / 兒童段另接 World Bank 嬰兒死亡率
- 死因分布：年齡分桶 + 國家 `deathCauses` 加權
